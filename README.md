# Smart Vocab

영어 단어를 **망각 곡선에 맞춰 복습**하는 개인용 단어장 앱입니다.
뜻을 직접 떠올려 적고, 정답과 비교해 맞음/틀림을 스스로 채점하는 방식입니다.

PC 버전(Python)과 같은 학습 규칙으로 동작하는 **안드로이드용 웹앱(PWA)** 이며,
폰 홈 화면에 설치하면 앱처럼 쓰고 오프라인에서도 실행됩니다.

## 주요 기능

- **추천 복습**: 복습할 때가 된 단어만 골라서 출제 (재학습 중인 단어 → 자주 틀린 단어 순)
- **오답률 집중 테스트**: 자주 틀리는 단어 위주로 출제
- **새 단어 학습**: 아직 한 번도 풀지 않은 단어 출제
- **틀린 것만 다시 풀기**: 테스트가 끝난 뒤 틀린 단어를 다 맞힐 때까지 반복 (학습 기록에는 반영 안 됨)
- **채점 화면**: 정답과 함께 동의어·반의어·관련어·메모, 예문과 해석 표시
- **단어 관리**: 검색, 정렬, 수정, 삭제, 학습 기록 초기화
- **단어 추가**: CSV 가져오기 또는 텍스트 붙여넣기 (미리보기에서 확인 후 반영)
- **백업**: JSON 백업/불러오기, CSV 내보내기

## 학습 규칙

- SM-2 방식을 바탕으로 맞힐수록 복습 간격이 길어집니다.
- 틀린 단어는 **재학습** 상태가 되어 1일 → 3일 → 7일 간격으로 다시 나오고,
  3번 연속 맞혀야 졸업합니다. 중간에 틀리면 처음부터 다시 시작합니다.
- 단어마다 난이도 계수(EF)가 있어서 쉬운 단어일수록 간격이 더 빨리 늘어납니다.

## CSV 형식

첫 줄에 열 이름을 적습니다. `word`와 `meaning`만 필수이고 나머지는 비워도 됩니다.

```
word,meaning,synonyms,antonyms,related,note,example,example_ko
abandon,버리다,desert,,,,"They had to **abandon** their car.",그들은 차를 버려야 했다.
```

- 동의어·반의어·관련어는 쉼표나 `;`로 여러 개 입력
- 예문 속 해당 단어를 `**`로 감싸면 채점 화면에서 굵게 표시
- 이미 있는 단어를 다시 가져오면 뜻과 학습 기록은 그대로 두고, 비어 있는 정보만 채움

## 데이터 저장

- 단어장은 폰 브라우저 내부 저장소(IndexedDB)에만 저장되며, 이 저장소(GitHub)에는 올라가지 않습니다.
- 문제를 하나 풀 때마다 바로 저장하고, 직전 저장본을 따로 보관해 손상 시 자동 복구합니다.
- PC 버전과 단어장은 따로 저장됩니다. 옮길 때는 JSON 백업이나 CSV를 사용합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| index.html | 화면 구조와 디자인 |
| app.js | 화면 동작, 저장, 백업/가져오기 |
| core.js | 학습 알고리즘, CSV 처리 (PC 버전과 같은 계산) |
| sw.js | 오프라인 동작 |
| manifest.webmanifest, icons/ | 홈 화면 설치용 정보와 아이콘 |

> 파일을 고쳐서 다시 올릴 때는 `sw.js`의 `VERSION` 값을 바꿔야 폰에 업데이트 안내가 뜹니다.
