📱 앱 음성 시험

이 페이지는 Smart Vocab 앱(APK) 안에서 열어야 해요. Chrome이나 홈 화면 웹앱에서는 동작하지 않습니다.

폰 내장 음성으로 예시 단어 12개를 반복해서 읽어요. 앱이 직접 읽기 때문에 화면이 꺼져도 계속 읽는지 확인합니다. 단어장과는 별개예요.

시험 방법
  1. 준비 — 위 '배터리 제한 해제'에서 허용, 알림 허용(앱 처음 열 때 물어봄). '폰 상태'에 영어·한국어가 '가능'인지
  2. 화면 켠 채 30초 — 단어 → 뜻이 이어서 나오는지, 알림창에 재생 표시가 뜨는지
  3. 화면 끄고 3분 — 이어폰으로 계속 들리는지 귀로 확인. 켠 뒤 기록의 "꺼진 ○분 동안 ○개 읽음" 확인
  4. 화면 꺼진 채 이어폰 버튼 — 한 번(멈춤) → 5초 뒤 한 번(재생: 소리가 다시 나는지) → 두 번(다음)
  5. 잠금 화면 알림 버튼으로도 멈춤·재생·다음 한 번씩
  6. 앱 나가기 — 홈 버튼으로 앱을 나가도 계속 읽는지
  7. 길게 5분 이상 화면 꺼 두기. 끝나면 '기록 복사' → Claude에게 붙여넣기 (들린 소리도 같이 알려 주세요)
