메뉴 이름은 One UI 버전에 따라 조금 다를 수 있어요.

시험 방법
  1. 화면 켠 채 1분 — 시작을 누르고 단어→뜻이 이어서 나오는지, 알림창·잠금 화면에 재생 표시가 뜨는지 확인
  2. 무음 켜기 + 화면 끄기 5분 — 시작 후 전원 버튼으로 화면을 끄고 5분 이상 듣기. 다시 켜서 기록의 "화면 꺼짐 ○분 동안 ○개"를 확인 (Chrome의 강한 절전이 5분 뒤부터 걸려서 5분 이상이 중요)
  3. 화면 꺼진 채 이어폰 버튼 — 한 번 누르기 = 멈춤/재생, 두 번 누르기 = 다음 단어. 기록에 "이어폰·잠금 화면"으로 남는지 확인
  4. 무음 끄기 + 화면 끄기 5분 — 2번과 비교 (무음 오디오가 정말 필요한지)
  5. 길게 15~20분 — 지하철 탈 때처럼. 끝나면 "기록 복사" → Claude에게 붙여넣기
