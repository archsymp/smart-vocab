🎧 듣기 시험 2차

음성 대신 신호음 파일로 시험해요. 화면이 꺼져도 파일이 다음 것으로 넘어가며 계속 소리가 나는지, 이어폰 버튼이 먹는지 확인합니다. 단어장과는 별개예요.

소리 읽는 법 — 한 항목 = 삐삐(짧게 두 번 = 단어 자리) → 삐—(낮고 길게 = 뜻 자리). 항목이 넘어갈 때마다 음이 조금씩 높아지고, 12번째 다음엔 다시 낮은 음으로 돌아가요. '다음'을 누르면 음이 한 칸 건너뛰어요.

방식

A = 파일을 하나씩 바꿔 재생 (본 기능 1순위) · B = Web Audio로 이어 재생 · C = 긴 파일 하나를 반복 (가장 안전한 대비책). 멈춘 상태에서만 바꿀 수 있어요.

기록
시험 방법 (방식마다)
  1. 화면 켠 채 30초 — 삐삐 → 삐— 가 반복되며 음이 점점 높아지는지
  2. 화면 끄고 3분 — 이어폰으로 소리가 계속 나는지 직접 들어 보기. 켠 뒤 기록의 "꺼진 ○분 동안 ○개"가 3분 기준 약 70개 근처면 정상
  3. 화면 꺼진 채 이어폰 버튼 — 한 번 누르기(멈춤) → 몇 초 뒤 한 번 더(재생) → 두 번 누르기(다음: 음이 건너뜀). 버튼마다 3초쯤 간격
  4. 잠금 화면 알림의 버튼도 한 번씩 눌러 보기 (이어폰과 구분하려고 따로)
  5. A가 되면 B·C는 화면 끄기 1분씩만 해도 충분. 끝나면 기록 복사 → Claude에게 붙여넣기
